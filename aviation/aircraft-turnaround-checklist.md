# Aircraft Turnaround Checklist

**For:** FBOs and charter operators  
**Use:** Between flights, before next passenger boarding

---

## Exterior

- [ ] Walkaround complete — no visible damage, fluid leaks, or foreign object debris
- [ ] Fuel caps secure
- [ ] Pitot covers removed
- [ ] Chocks removed prior to engine start
- [ ] Tow bar stowed
- [ ] Tie-downs stowed or removed

## Cabin

- [ ] Cabin vacuumed and wiped down
- [ ] Seat belts laid flat and visible
- [ ] Seat pockets clear of previous passenger items
- [ ] Window shades up (or per passenger preference)
- [ ] Cups, bottles, trash removed
- [ ] Lavatory (if equipped): restocked, cleaned, waste door secured

## Documents

- [ ] Aircraft logbook current
- [ ] Current charts / approach plates loaded (or EFB verified current)
- [ ] Passenger manifest updated for next flight
- [ ] Weight and balance completed for next load

## Crew

- [ ] Pilot rest requirements verified
- [ ] Weather briefed for next leg
- [ ] NOTAMs reviewed
- [ ] FBO / ground services confirmed at destination

---

*Adapt to your aircraft type and operation. This is a starting point, not a regulatory document.*
