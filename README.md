# BSM Field Playbook

Operational guides, checklists, and SOPs for aviation operators, restaurant owners, and skydiving dropzones — free to use, adapt, and improve.

Built and maintained by [Blue Skies Matter](https://www.blueskiesmatter.com).

---

## What's Here

### ✈️ Aviation
Practical resources for FBOs, charter operators, flight schools, and maintenance shops.

- Aircraft turnaround checklists
- Charter client intake forms
- Pilot briefing formats
- FBO front-desk SOPs
- Maintenance log templates

### 🍽️ Restaurants
Opening/closing procedures, training guides, and POS integration resources.

- Opening and closing checklists
- New server training guide
- SpotOn POS onboarding workflow
- Inventory tracking templates
- Health inspection prep checklist

### 🪂 Dropzones
Manifest templates, student briefing guides, and operational frameworks.

- Student manifest templates
- Tandem briefing scripts
- Weather hold communication guide
- Gear room SOPs
- Seasonal staffing frameworks

---

## How to Use

Every document in this repo is in Markdown or PDF format. You're free to:
- Download and use as-is
- Fork and adapt for your operation
- Submit improvements via pull request

No attribution required, though we appreciate a mention.

---

## Contributing

If you work in aviation, food service, or adventure sports and have a resource worth sharing, open a pull request or [reach out](https://www.blueskiesmatter.com/contact?venture=oss).

We review contributions weekly.
